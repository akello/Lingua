# Lingua

Приложение для Android, помогающее ребёнку учить английские слова.
Первое упражнение — «Соедини слова»: слева русские слова, справа английские, нужно соединить пары.

## Как это выглядит

- 8 пар за раунд, два перемешанных столбика.
- За верную пару +10 ⭐, за серию из трёх и более — ещё +5, за ошибку −3, за раунд без ошибок +20.
- 11 званий-животных: от 🐣 Цыплёнка до 🐉 Дракона. Звание не понижается, фон меняется с каждым новым.
- Верное английское слово произносится вслух (встроенный синтезатор речи Android).
- Скрытый раздел для родителей: удерживать зверька на главном экране 3 секунды, решить пример, посмотреть статистику или сбросить достижения.

## Списки слов

Списки — обычные txt-файлы в репозитории [lingua-words](https://github.com/akello/lingua-words), папка `lists`.
Приложение скачивает их при запуске и сохраняет копию, поэтому работает и без интернета.

Формат простой: одна строка — одна пара. Где английский, а где русский, приложение определяет по буквам,
поэтому порядок и разделитель любые:

```
кошка, cat
собака dog
cat - кошка
мороженое; ice cream
a cake — пирожное, торт
# строки с решёткой и пустые пропускаются
```

Имя файла становится названием списка: `01_Животные.txt` → «Животные», цифры задают порядок.

## Сборка

Нужна Android Studio. Открыть папку проекта, дождаться синхронизации Gradle, нажать ▶ Run.

Для сборки подписанного APK скопируйте `keystore.properties.example` в `keystore.properties`,
впишите путь к своему ключу и пароли, затем выполните:

```
./gradlew assembleRelease
```

Готовый файл: `app/build/outputs/apk/release/lingua-<версия>-release.apk`.

Файл ключа и `keystore.properties` в репозиторий не попадают.

## Техника

Kotlin, Jetpack Compose, Material 3, minSdk 26. Без сторонних библиотек: сеть на HttpURLConnection,
достижения в SharedPreferences, озвучка через TextToSpeech.
